# Browser Autopilot

一个浏览器自动化工具，可以无感知地记录用户操作，通过 AI 分析生成可复用的工作流，并通过自然语言执行。

## 架构

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ Chrome 扩展     │────▶│  操作录制引擎   │────▶│  操作序列化存储 │
│ (无感知记录)    │     │  (事件捕获)     │     │  (IndexedDB)    │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                         │
                                                         ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  Playwright执行 │◀────│   LLM 分析器    │◀────│  操作流程库     │
│  (自动化执行)   │     │  (生成工作流)   │     │  (持久化存储)   │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

## 功能特性

### 1. 无感知操作录制
- 后台记录所有用户操作：点击、输入、滚动、导航等
- 自动生成稳定的 CSS 选择器
- 防抖和去重处理，避免冗余记录

### 2. AI 智能分析
- 基于 GPT-4 的操作序列分析
- 自动识别操作意图
- 生成可复用的工作流
- 合并冗余操作，添加等待条件

### 3. 工作流管理
- IndexedDB 本地存储
- 标签分类和搜索
- 导出为 Playwright/Puppeteer 代码

### 4. 自然语言执行
- 自然语言查询匹配工作流
- 基于语义的智能匹配
- 一键生成可执行代码

## 安装

### 1. 安装依赖
```bash
npm install
```

### 2. 构建 Dashboard
```bash
npm run build
```

### 3. 加载 Chrome 扩展
1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启 "开发者模式"
3. 点击 "加载已解压的扩展程序"
4. 选择项目的 `extension` 文件夹

## 使用说明

### 录制操作
1. 安装扩展后，自动开始录制
2. 正常浏览网页，操作会被后台记录
3. 点击扩展图标可以暂停/开始新会话

### 分析工作流
1. 点击扩展图标 → "Open Dashboard"
2. 在 "Sessions" 标签页选择一个会话
3. 点击 "Analyze & Create Flow" 进行 AI 分析
4. 可以配置 OpenAI API Key 获得更好的分析效果

### 执行工作流
1. 在 "Execute" 标签页输入自然语言描述
2. 系统会自动匹配最相关的工作流
3. 复制生成的 Playwright 代码并运行

## 目录结构

```
autopilot-dashboard/
├── extension/              # Chrome 扩展
│   ├── manifest.json       # 扩展配置
│   ├── popup.html          # 弹出面板
│   ├── popup.js            # 面板逻辑
│   ├── content-script.js   # 内容脚本（事件捕获）
│   └── background.js       # 后台脚本（数据存储）
├── src/
│   ├── recorder/           # 录制模块
│   │   ├── types.ts        # 类型定义
│   │   ├── event-capturer.ts    # 事件捕获器
│   │   └── selector-generator.ts # 选择器生成
│   ├── llm/                # AI 分析模块
│   │   └── flow-analyzer.ts      # 流程分析
│   ├── storage/            # 存储模块
│   │   └── flow-db.ts      # IndexedDB 封装
│   ├── executor/           # 执行模块
│   │   └── playwright-runner.ts  # 代码生成
│   ├── App.tsx             # Dashboard 主界面
│   └── main.tsx            # 入口
└── package.json
```

## 技术栈

- **前端**: React + TypeScript
- **扩展**: Chrome Extension Manifest V3
- **存储**: IndexedDB
- **AI**: OpenAI GPT-4
- **自动化**: Playwright

## 注意事项

1. **隐私**: 所有操作数据存储在本地，不会上传到任何服务器
2. **敏感信息**: 录制操作可能包含密码等敏感信息，注意不要导出分享
3. **性能**: 录制过程对浏览性能影响很小，每秒最多记录 10 个操作
